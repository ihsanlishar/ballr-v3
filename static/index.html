How to read this

Each card is one upcoming match. The bar shows Ballr's predicted Win/Draw/Win split.

  • Model — an Elo rating system built from each team's real results this season, combined with a Monte Carlo simulation (thousands of simulated outcomes) to produce a probability for each result.
  • Scorelines and xG — a separate Poisson projection converts the same Elo strength signal into expected goals and exact-score probabilities. It is a model projection, not event-level xG.
  • Home advantage is factored in, based on real backtested evidence, not just assumed.
  • Known limitation: ratings are based purely on this season's match results so far — squad changes, transfers, and injuries aren't yet factored in. Early-season predictions for teams with few games played (marked below) are less reliable.

Not betting advice — a model's opinion, nothing more. Backtested Brier score (lower is better, ~0.667 is random guessing): ~0.61-0.63 on last season's results.
